# Banking REST API

## Overview
A REST API Banking Application built using FastAPI.

## Features
- Create Account
- Deposit Money
- Withdraw Money
- Get Account Details
- Get All Accounts

## Technology
- Python
- FastAPI
- Pydantic

## Installation

```bash
pip install fastapi uvicorn pydantic
```

## Run

```bash
uvicorn main:app --reload
```

## Swagger UI

http://127.0.0.1:8000/docs
